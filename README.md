# PII Document Viewer

A single static page that shows the 200 synthetic document images from the
[hussain-khalid/pii-dataset](https://huggingface.co/datasets/hussain-khalid/pii-dataset) dataset,
with every labelled PII field outlined and named on the image.

## What it shows

- 200 document images: 73 ID cards, 70 invoices and 57 forms (166 train / 19 validation / 15 test).
- 820 labelled fields across six labels: `PERSON`, `EMAIL`, `PHONE`, `ADDRESS`, `ID_NUMBER`, `DATE_OF_BIRTH`.
- Under each image: its id, document type, split and the list of labelled fields.
- A checkbox to show or hide the boxes.

All names, addresses, emails, phone numbers, ID numbers and dates of birth are synthetic. The dataset
contains no real person's data.

## Layout

| Path | Contents |
| --- | --- |
| `index.html` | The page. Generated by `scripts/build.py`; no JavaScript, no dependencies. |
| `images/` | The 200 document images, unchanged from the dataset. |
| `data/` | The dataset's label files (`train`, `validation`, `test` Parquet). |
| `scripts/build.py` | Reads `data/` and writes `index.html`. |

## Rebuild the page

```bash
pip install pyarrow
python scripts/build.py
```

The script also checks that every image matches its stated size and every box lies inside its image.

## Deployment

The site is a static page with no build step. `.vercelignore` keeps `data/` and `scripts/` off the
deployed site.
